# Отчет по тестированию рекомендательной системы для игр Steam

**Проект:** Рекомендательная система для Steam  
**Тип системы:** Content-Based рекомендательная система с использованием SVD-разложения

---

## Введение

В рамках проекта была разработана рекомендательная система, основанная на анализе признаков игр из датасета Steam. Система использует подход **item-to-item**, при котором пользователю, просматривающему конкретную игру, предлагаются другие игры, наиболее похожие по набору характеристик. Для построения рекомендаций применяется метод **TruncatedSVD**, позволяющий сократить размерность пространства признаков и выделить наиболее значимые латентные факторы, определяющие сходство между играми.

Цель тестирования заключалась в проверке корректности работы всех компонентов системы, включая:
- загрузку и очистку данных,
- обучение модели,
- создание эмбеддингов,
- вычисление матрицы сходства,
- формирование рекомендаций,
- сохранение модели.

Дополнительной задачей являлась оценка релевантности рекомендаций на основе анализа предложенных системой игр.

---

## Объект тестирования

Объектом тестирования являлась рекомендательная система, реализованная в виде набора Python-скриптов и Jupyter-ноутбука. Система обрабатывает датасет игр Steam, содержащий информацию о **27 075** играх.

В процессе предобработки данных были созданы **375 признаков**, включающих:
- бинарные признаки для жанров, категорий, платформ и тегов;
- числовые признаки, такие как рейтинг, цена и закодированный разработчик.

Для обучения модели использовался алгоритм **TruncatedSVD** с **29 компонентами**, что позволило сохранить **90%** объясненной дисперсии исходных данных. Итоговые эмбеддинги игр имеют размерность **29** и используются для вычисления косинусного сходства между играми.

---

## План тестирования

Тестирование проводилось по следующим направлениям:

1. Проверка корректности загрузки данных из внешнего источника и выполнения всех этапов предобработки.
2. Тестирование процесса обучения модели и создания эмбеддингов игр.
3. Проверка работоспособности функции формирования рекомендаций для различных игр.
4. Проверка сохранения и последующей загрузки модели.
5. Качественная оценка релевантности рекомендаций на основе анализа предложенных системой игр для четырех тестовых игр из разных жанров.

---

## Результаты тестирования

### Загрузка и предобработка данных

Датасет был успешно загружен с платформы Kaggle. Общее количество загруженных записей составило **27 075** игр.

В процессе предобработки были выполнены следующие действия:
- заполнены пропуски в полях разработчика и издателя;
- созданы новые признаки, включая год выпуска, долю положительных отзывов и среднее количество владельцев;
- выполнено преобразование текстовых признаков в бинарный формат с помощью One-Hot кодирования.

Итоговая матрица признаков содержит **375 столбцов**, что полностью соответствует ожидаемой структуре.

---

### Обучение модели

Модель TruncatedSVD была обучена на полной матрице признаков. Количество компонент было выбрано равным **29** на основе анализа накопленной объясненной дисперсии, которая составила **90%** от исходной.

Это означает, что модель успешно сжала исходное 375-мерное пространство признаков в 29-мерное латентное пространство, сохранив при этом основную информацию о структуре данных.

Матрица эмбеддингов игр имеет размерность **27 075 × 29**.

---

### Матрица сходства

На основе полученных эмбеддингов была вычислена матрица косинусного сходства размером **27 075 × 27 075**.

- Проверка диагональных элементов показала, что все значения равны **1.0** с высокой точностью, что подтверждает корректность вычислений.
- Значения сходства между различными играми распределены в диапазоне от -1 до 1, при этом большинство значений находятся в положительной области, что указывает на наличие общих паттернов между играми.

---

### Функция рекомендаций

Функция рекомендаций была протестирована на четырех играх:
- **Counter-Strike**
- **Stardew Valley**
- **DOOM**
- **Portal 2**

Для каждой игры система успешно возвращала список из трех рекомендаций с указанием коэффициента сходства.

**Важные особенности:**
- функция корректно обрабатывает случаи частичного совпадения названий;
- возвращает сообщение об ошибке при вводе несуществующей игры.

Все тестовые сценарии были выполнены без возникновения исключительных ситуаций.

# Отчет по оценке качества на тестовой выборке

## Цель оценки

Для объективной проверки качества разработанной рекомендательной системы было проведено тестирование на разделенных данных. Основной задачей являлась проверка способности модели обобщать выявленные закономерности и формировать релевантные рекомендации для игр, не участвовавших в процессе обучения.

В качестве метрики качества использовалась **Precision@5**, которая показывает долю релевантных рекомендаций среди пяти предложенных системой вариантов.

---

## Методология

### Разделение данных
- **Обучающая выборка:** 21 660 игр (80%)
- **Тестовая выборка:** 5 415 игр (20%)

### Процедура тестирования
1. Модель TruncatedSVD с 29 компонентами была обучена исключительно на обучающей выборке.
2. Для каждой игры из тестовой выборки вычислялись эмбеддинги с использованием обученной модели.
3. Для каждой тестовой игры находились пять наиболее похожих игр из обучающей выборки на основе косинусного сходства.
4. Релевантность рекомендации определялась по наличию **хотя бы одного общего жанра** между рекомендованной и исходной игрой.
5. Для оценки использовались **200 случайных игр** из тестовой выборки.

---

## Результаты оценки

| Метрика | Значение |
|---------|----------|
| **Precision@5** | **0.727** |
| **Средний коэффициент сходства** | **0.926** |

### Интерпретация результатов

- **Precision@5 = 0.727** означает, что в среднем **72.7%** рекомендаций имеют общий жанр с исходной игрой.
- **Средний коэффициент сходства 0.926** подтверждает близость векторных представлений рекомендованных игр к исходным.

Полученные результаты свидетельствуют о том, что модель успешно выделяет значимые признаки игр и находит семантически близкие объекты даже для игр, не присутствовавших в обучающей выборке.

## Выводы по оценке на тестовой выборке

Проведенная оценка на тестовой выборке подтверждает, что модель демонстрирует устойчивое качество при формировании рекомендаций для игр, не использовавшихся при обучении.

**Ключевые результаты:**
- **Precision@5 = 0.727** — более двух третей рекомендаций являются релевантными с точки зрения жанрового соответствия.

Полученные результаты свидетельствуют о том, что выбранный подход на основе **SVD-разложения** и **косинусного сходства** успешно обобщает выявленные закономерности и может применяться для формирования рекомендаций новым пользователям или для новых игр, добавляемых в систему.
